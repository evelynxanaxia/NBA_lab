# Scaling and Running Cluster
Before running the clustering model, players with fewer than 20 games played were filtered out. Players with very limited appearances don't give us enough data to reliably evaluate their performance, so including them could skew the results. The remaining players were then scaled using a technique called standardization. This is necessary because clustering algorithms measure distance between data points. And if salary is in the millions and points per game is in the single digits, salary would dominate the results simply because of its larger scale. Standardizing puts all variables on the same scale so each one contributes equally to the groupings.
The clustering model used is called K-Means. The idea is to basically create a model that tries to group players into K clusters so that players within the same group are as similar to each other as possible. As a first attempt, the model was run with K=3 (three groups).
# Results
After running the model with three clusters, the quality of the groupings was evaluated using two measures: the Total Variance Explained and the Silhouette Score.
Total Variance Explained: 0.41this means the three clusters explain about 41% of the variation in the data. It is basically giving us a grade of  41% which tells us the model is capturing some real patterns but is not as clean as we would like.
Silhouette Score: 0.18 this measures how separated the clusters are from each other. Scores range from -1 to 1, the higher the number the better the model is. A score of 0.18 is relatively low, suggesting the three clusters overlap quite a bit and are not very distinct.These results suggested that three clusters might not be the ideal choice for this data and we need to change it.
# Elbow Method
To find the best number of clusters, two diagnostic methods were used, the Elbow Method and the Silhouette Score across multiple values of K. The Elbow Method plots how tightly packed the clusters are (called inertia) as K increases. The goal is to find the point where adding more clusters stops providing much improvement in which the inflection point looks like an elbow on the chart.
The Silhouette Score was also calculated for K values from 2 through 9. Both methods pointed toward K=2 as the most appropriate choice for this data, meaning players are best separated into two groups: high performers and lower performers.
